# ReAct Agent · 模块二：按部门划分工具箱

> **喂食核心 · 模块二**（依赖 [模块一](./01-模块一-背景-跨部门功能-语气.md)）  
> 原则：**工具只实现一次**（`shared/tools`）；部门差异 = Skill 的 `allowed_tools` 白名单  
> 版本：V1.0 · 2026-08-02

---

## 0. 读法

| 概念 | 含义 |
|------|------|
| **全局工具池** | `ToolRegistry` 里全部 tool，各部门不复制实现 |
| **部门工具箱** | 该部门 ReAct Skill **允许调用**的子集（白名单） |
| **必选 / 可选** | 必选 = 该功能闭环离不开；可选 = 增强或跨域只读 |

反孤岛要点：服务填单写的 `write_ai_output`，与用户运营读的 `read_ai_outputs` / `check_outreach_block`，是**同一套工具**，不是两套 API。

## 2. 分部门工具箱

> 每部门 = 模块一功能 → **必选工具** + **可选工具** + **绑定 Skill**。  
> 「共用底盘」几乎每箱都带：`log_step`；写资产加 `write_ai_output`；读资产加 `read_*`。

### 2.1 服务事业部 · 稳妥确认型

| 功能 | Skill | 必选工具箱 | 可选 |
|------|-------|------------|------|
| 智能填单 F-SVC-001 | `fill_ticket` ✅ | `get_customer`, `get_vehicle`, `get_ticket`, `list_tickets`, `extract_ticket_fields`, `suggest_voc_tags`, `get_tag`, `write_ai_output`, `log_step` | `get_telemetry`, `search_kb`(repair) |
| 维修客服多步 F-SVC-003 | `crm_lookup` + kb 域 | `get_customer`, `get_vehicle`, `list_tickets`, `search_kb`, `get_kb_document`, `get_telemetry`, `log_step` | `list_quality_checks`, `write_ai_output` |

**白名单（与 catalog 一致 · `fill_ticket`）**

```text
get_customer, get_vehicle, get_ticket, list_tickets,
extract_ticket_fields, suggest_voc_tags, get_tag,
write_ai_output, log_step
```
