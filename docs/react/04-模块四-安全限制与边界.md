# ReAct Agent · 模块四：安全限制与边界

> **喂食核心 · 模块四**（依赖模块一～三）  
> 原则：**边界写进代码闸门**，Prompt 只作补充；共用手脚不等于放开权限  
> 版本：V1.0 · 2026-08-02

---

## 1. 边界总览（六层）

```text
L1 身份 / 合成数据     VIN=QS0… · customer_id=CUS-… · 禁止真实品牌入库
L2 工具权限             Skill allowed_tools 白名单 · producer_skill 一致
L3 共享资产             PII/密钥禁写 · consumer_allow · 阻断标签
L4 部门 / Skill         kb 域双闸 · 单步 tool 上限 · 语气禁用项
L5 控制环               max_steps（仅工具轮）· 成功后另开终答轮 · observation 脱敏
L6 运行机密 + 范围声明   API Key 环境变量；不做生产鉴权（见 §7.2）
```

| 层 | 主要落地 | 失败码 / 停止理由（示例） |
|----|----------|---------------------------|
| L1 | `shared/tools/guards.py` | `VIN_NOT_SYNTHETIC`, `INVALID_CUSTOMER_ID` |
| L2 | `ToolRegistry._assert_allowed` | `TOOL_NOT_ALLOWED`, `PRODUCER_MISMATCH` |
| L3 | `guard_payload` / `check_outreach_block` | `PII_FORBIDDEN`, `SECRET_FORBIDDEN` |
| L4 | `skill.yaml` → `security` + tool `kb_domains_allow` 双闸 | `KB_DOMAIN_DENIED`, `TOO_MANY_TOOL_CALLS` |
| L5 | `agents/react/agent.py` | `max_steps`, `success` / `success_forced`, `security_stop` |
| L6 | `.env` + 范围声明 | 缺 key 不启动 LLM；不声称企业 ACL |

---

## 2. L1 · 身份与合成数据

| 规则 | 说明 |
|------|------|
| VIN | 必须 17 位且前缀 `QS0` |
| customer_id | 必须 `CUS-` 前缀 |
| 知识库域 | 仅 `repair/policy/hr/product/channel` |
| 企业叙事 | 仅「青枢出行」虚构品牌；禁止把真实客户材料当种子 |

Agent 侧：工具已拒时，终答应说明「Demo 仅接受合成 ID」，不得编造真实号段。

---

## 3. L2 · 工具权限

| 规则 | 说明 |
|------|------|
| Skill 白名单 | `allowed_tools`；未列出的 tool → `TOOL_NOT_ALLOWED` |
| 禁止互偷工具 | 例：`fill_ticket` 不得 `score_renewal`（smoke 已锁） |
| 写入冒充 | `write_ai_output.producer_skill` 必须等于 `context.skill_id` |
| 未知参数 | `additionalProperties=false` → `UNKNOWN_ARG` |
| 体积 | 文本 ≤4000 字；payload ≤32KB；list limit ≤100 |

跨部门协作：**只读共享产出 / 标签**，不开放对方业务写工具。

---

## 4. L3 · 共享资产与触达闸门

| 规则 | 说明 |
|------|------|
| 禁明文手机号 | payload 含 `1[3-9]xxxxxxxxx` → `PII_FORBIDDEN` |
| 禁密钥形态 | payload 含 `sk-…` / `API_KEY=` 等 → `SECRET_FORBIDDEN` |
| 消费授权 | `consumer_allow` 控制谁能 `read_ai_outputs` |
| 触达阻断 | 存在 `TAG-投诉未结` / `TAG-舆情风险` / `TAG-安全隐患` 时 `allow_outreach=false`（Story2） |

ReAct 若挂续费类 Skill 且 `security.block_on_outreach=true`：一旦 `check_outreach_block.blocked=true`，控制环 **立即停止**，不得继续促销话术。

---

## 5. L4 · 部门 / Skill 安全槽（`security`）

见 `skills/SCHEMA.md` 与各 `skill.yaml`：

| 字段 | 含义 |
|------|------|
| `kb_domains_allow` | 非空时限制 `search_kb` / `get_kb_document` / `list_kb_domains`（防绕域） |
| `max_tool_calls_per_step` | 单轮 LLM 返回的 tool_calls 上限 |
| `redact_pii_in_observation` | 回灌模型前脱敏 observation |
| `block_on_outreach` | 读到阻断标签则 `security_stop` |
| `prompt_forbid_extra` | 追加进 Prompt 的硬禁表述 |

### 5.1 一期 Skill 绑定

| Skill | 部门 | 关键边界 |
|-------|------|----------|
| `fill_ticket` | 服务 | 禁超权赔付承诺；写产出禁 PII；不可碰续费打分工具 |
| `crm_lookup` | 共用查询 | 只读主数据；不写共享层 |
| `channel_ops` | 渠道 | 中性表述；不人身攻击经销商 |
| `shared_write` | 系统 | 中性系统腔；强 PII/密钥闸 |

## 6. L5 · 控制环硬闸

| 闸门 | 行为 |
|------|------|
| `max_steps` | **只约束带 tools 的工具轮**（`for step in 1..max_steps`） |
| 成功 +1 终答轮 | 成功后 **跳出工具循环**，另开 1 次 `tools=None` 调用；与 max_steps 计数分离 |
| 终答轮仍 tool_call | → `success_forced`（已成功，不再执行工具） |
| 未成功跑满 max_steps | → `max_steps`，**不会**再多给一轮带 tools 的调用 |
| 单步 tool 过多 | → `security_stop` / `TOO_MANY_TOOL_CALLS` |
| kb 域越权 | Agent 预检 + `ToolContext.kb_domains_allow` 在 `search_kb` / `get_kb_document` / `list_kb_domains` 双闸 |
| observation 脱敏 | 手机号 → `1**********` 再给模型 |
| 连续越权/坏参 | `tool_denied` / `bad_args` |

## 7. L6 · 运行机密与「不做生产鉴权」边界

### 7.1 运行机密（本 Demo 要做）

- `DEEPSEEK_API_KEY` 仅 `.env` / 环境变量（已 gitignore）  
- Prompt、日志、`AIOutput` 不得回显完整 key  

### 7.2 「生产级鉴权不做」是什么意思（范围声明，不是待办缺口）

| 维度 | 本 Demo **有** | 本 Demo **明确没有 / 不做** |
|------|----------------|-----------------------------|
| 信任模型 | **本地可信操作者**跑 CLI | 多租户、公网匿名用户 |
| 权限模型 | **Skill 工具白名单** + 合成 ID 校验 + 共享产出 `consumer_allow` | SSO / OAuth / RBAC / 行级数据权限 |
| 身份 | `skill_id` + `run_id` 审计字段 | 员工账号、门店账号、经销商账号体系 |
| 审计 | `log_step` / run 日志（Demo 级） | 合规级不可篡改审计、密钥托管 KMS |

**表述规范：**

- 可写：Skill 级工具隔离与共享层消费授权（防 AI 孤岛示意）  
- 不可写：已具备企业生产鉴权 / 权限中台  

若未来产品化，鉴权属于 **独立分期**，不在本作品集 ReAct 模块范围内补齐。

## 8. 与 Prompt 的分工

| 机制 | 负责 |
|------|------|
| 代码闸门 | 能不能调、能不能写、停不停 |
| Prompt（语气 forbid + security 附录） | 怎么说、不承诺什么 |
| 模块一禁用项 | 喂给 `tone.forbid`，不替代代码 |

拼接：在既有 `PROMPT_SECTION_ORDER` 末尾增加 **`F_security`**（模块四），由 `build_system_prompt` 自动附上安全摘要。
