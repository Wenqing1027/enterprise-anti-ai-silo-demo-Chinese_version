# AI功能需求清单

> **企业场景**：智能电动车出行（作品集映射：青枢出行 / Qingshu Mobility）  
> **来源**：绿源内部材料梳理（AI体系网络、XMind规划、VoC、续费漏斗、BIS、渠道激活、用户运营、业务流转等）  
> **口径**：只管「要什么功能」，不管数据是否齐全  
> **版本**：V1.0 · 2026-08-01  
> **用途**：作品集 Demo 功能地图 / 后续 Skill 挂载依据；**禁止**写入真实客户名于代码与合成数据叙事中直接暴露为生产交付

## 使用说明

| 列 | 含义 |
|----|------|
| 功能ID | 稳定编号，供 Skill / CapabilityCatalog 引用 |
| 功能名称 | 材料原名或合理归并名 |
| 一句话目的 | 业务要达成什么 |
| 归属部门 | 主责部门（推断已标注） |
| Agent类型建议 | RAG / Planning / ReAct / Extraction / Rule+LLM / Vision |
| 关联报表/产出 | 若有报表类产出则列出 |
| 备注 | 跨部门、推断、硬条件等 |
