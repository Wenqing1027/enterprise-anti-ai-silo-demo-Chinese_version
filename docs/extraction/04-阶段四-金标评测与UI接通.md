| 项 | 路径 |

## 2. 门槛（与阶段一一致）

### ticket_fields

| 指标 | 门槛 |
|------|------|
| Schema 合规率 | 100% |
| ticket_type | ≥80% |
| fault_category（fault 子集） | ≥75% |
| tag_id Top-1（含 accept 集） | ≥75% |
| 阻断漏报 | 0 |
| sentiment | ≥80%（非投诉句允许 `neu↔neg` 一档容忍，验收用容忍口径） |
| ID 召回（有明示） | ≥95% |

### voc_entities

| 指标 | 门槛 |
|------|------|
| Schema 合规率 | 100% |
| tag_id | ≥80% |
| 阻断漏报 | 0 |
| sentiment | ≥85% |
| tag_domain | ≥90% |
| 字典外标签率 | ≤5% |

评测时 `write_output=false`，不污染共享产出；阻断标签按主标签或 `secondary_tag_ids` 命中计。

---

## 3. 怎么跑评测

```bash
source .venv/bin/activate
python scripts/eval_extraction.py
# 调试可限条：
# python scripts/eval_extraction.py --limit 3
# python scripts/eval_extraction.py --ticket-only
```

成功退出码 `0` = 两套均达门槛；报告写入：

- `docs/extraction/eval_reports/latest.md`
- `docs/extraction/eval_reports/eval-<timestamp>.md`
