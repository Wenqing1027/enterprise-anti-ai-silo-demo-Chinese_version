# 标准字段定义表

> **口径**：不管谁用，只管「用什么数据」——从 AI 功能与报表字段泛化而来的统一数据字典  
> **企业场景**：智能电动车出行（作品集：青枢出行）  
> **版本**：V1.0 · 2026-08-01  
> **配套**：同目录 `标准字段定义表.csv`（可导入建模）；功能侧见 `AI功能需求清单.md`  
> **落地映射**：优先进入 `shared/models` 的实体为 Customer / Vehicle / Ticket / Order / TagVocabulary / AIOutput，其余字段作为扩展属性或报表视图

---

## 0. 使用规则

| 规则 | 说明 |
|------|------|
| 去部门化 | 字段不归属部门，只归属数据域/实体 |
| 一义一名 | 同一业务含义只保留一个 `field_name`（如销量统一 `sales_qty`） |
| 行业有意义示例 | `example` 按两轮智能电动车场景填写，便于合成数据 |
| 报表复用 | `related_reports` 仅作溯源，不是权限模型 |
| Demo 最小核 | 标 ★ 的实体优先实现 Pydantic models |
