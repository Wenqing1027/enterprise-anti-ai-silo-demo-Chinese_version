# RAG · 控制环实现与接通（R4）

> **喂食核心 · RAG R4**  
> 控制环：`retrieve → stuff → generate`（+ 引用）  
> LLM：DeepSeek（`profile=rag` → `DEEPSEEK_RAG_API_KEY` 回落 `DEEPSEEK_API_KEY`）  
> 版本：V1.0 · 2026-08-05

---

## 1. 实现位置

| 路径 | 角色 |
|------|------|
| `agents/rag/agent.py` | 控制环 |
| `agents/rag/prompts.py` | System / User 拼装 |
| `apps/cli.py --agent-type rag` | CLI |
| `POST /v1/rag/runs` | API |
| `scripts/smoke_rag.py` | 端到端冒烟 |

---

## 2. 环境变量

```bash
# .env（勿提交）
DEEPSEEK_RAG_API_KEY=sk-...
# 或回落
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_RAG_MODEL=deepseek-chat
DEEPSEEK_RAG_TEMPERATURE=0.2
```

---

## 3. 运行

```bash
python apps/cli.py --agent-type rag --skill repair_kb \
  --input '{"query":"续航低于标称怎么排查？"}'

python scripts/smoke_rag.py
```

API：

```bash
curl -s localhost:8000/v1/rag/runs -H 'Content-Type: application/json' \
  -d '{"skill_id":"repair_kb","input":{"query":"续航低于标称怎么排查？"}}'
```

---

## 4. 步骤语义

| phase | 行为 |
|-------|------|
| retrieve | `DataFetcher.search_kb`，域=`kb_domains_allow` |
| stuff | 按 `max_context_chars` 装填片段 |
| generate | DeepSeek 生成终答 |
| cite / cite_backfill | 校验或补全 `kb_chunk_id` 引用 |

成功：`stop_reason=cited_answer`（有命中）或 `no_hit_answered`（允许无命中说明）。
