# RAG · 文档切块策略（R1）

> **喂食核心 · RAG R1 前置**  
> 源文档：`data/knowledge/{repair,policy,hr,product,channel}/*.md`  
> 机读产物：`data/knowledge/chunks.json`  
> 构建脚本：`scripts/build_kb_chunks.py`  
> 切块实现：`shared/rag/chunking.py`  
> 版本：V1.0 · 2026-08-05

---

## 1. 目标

把合成知识长文切成可检索、可引用的片段，供后续索引（TF-IDF/向量）与 RAG 控制环 `retrieve` 使用。

| 原则 | 说明 |
|------|------|
| 源文只读 | 不改 `*.md` 正文；切块为派生资产 |
| 语义优先 | 优先按 Markdown `##` 小节切，避免拦腰切断步骤表 |
| 可引用 | 每块有稳定 `kb_chunk_id`，终答可回指 |
| 可重跑 | `python scripts/build_kb_chunks.py` 覆盖生成，不手改 JSON |
| 统一出口 | 检索仍经 DataFetcher / `search_kb`（下一步 R2 接上） |

---

## 2. 切块规则

### 2.1 参数（一期默认）

| 参数 | 默认 | 含义 |
|------|------|------|
| `max_chunk_chars` | `520` | 单块上限（中文约 260～400 token 量级示意） |
| `min_chunk_chars` | `48` | 过短块尝试与下一块合并（保留 heading 元数据） |
| `overlap_chars` | `64` | 仅窗切时重叠，保留跨段上下文 |
| `heading_levels` | `##` | 主分割点；`#` 标题进文档级 `title`，不单独成块 |

### 2.2 算法（有序）

```text
1. 读 index.json → 定位 md → 取全文
2. 去掉首行 # 标题后，按 ## 切成「节」
3. 每一节：
   - 若 长度 ≤ max_chunk_chars → 整节一块
   - 若 超长 → 按空行/段落再切；仍超长则固定窗长 + overlap
4. 相邻过短块（< min）合并，合并后仍 ≤ max
5. 块正文前缀写入「文档标题 › 节标题」路径，便于检索与引用
6. 写出 chunks.json（含 manifest 统计）
```

### 2.3 ID 约定

| 字段 | 格式 | 例 |
|------|------|-----|
| `kb_doc_id` | 沿用 index | `repair__续航异常排查` |
| `kb_chunk_id` | `{kb_doc_id}#c{nnnn}` | `repair__续航异常排查#c0001` |
| `section_path` | `文档标题 › 节标题` | `续航异常排查手册 › 2. 快速区分` |
| `char_start` / `char_end` | 相对**源全文**的 UTF-8 字符偏移（近似） | 用于调试，非硬门禁 |

`#c` 序号在**同一文档内**从 `0001` 递增；重跑同一源文顺序稳定。

## 3. 落盘位置

| 路径 | 角色 |
|------|------|
| `data/knowledge/**/*.md` | 源文档（真人读 + 生成器种子） |
| `data/knowledge/index.json` | 文档级目录（已有） |
| **`data/knowledge/chunks.json`** | **切块机读真相（本步产物）** |
| `docs/rag/04-文档切块策略.md` | 本文（人读策略） |
| `shared/rag/chunking.py` | 切块纯函数，可被脚本与后续索引共用 |

**禁止**：`scripts/generate_synthetic_data.py` 覆盖 `chunks.json`（与 `department_flows.json` 同约定：手工/专用脚本维护）。

## 4. `chunks.json` Schema（摘要）

```json
{
  "version": "v1",
  "strategy_id": "heading_then_window_v1",
  "params": { "max_chunk_chars": 520, "min_chunk_chars": 48, "overlap_chars": 64 },
  "built_at": "ISO-8601",
  "source_index": "knowledge/index.json",
  "stats": { "docs": 15, "chunks": N, "by_domain": { "repair": … } },
  "chunks": [
    {
      "kb_chunk_id": "repair__续航异常排查#c0001",
      "kb_doc_id": "repair__续航异常排查",
      "kb_domain": "repair",
      "title": "续航异常排查",
      "section_heading": "1. 现象确认",
      "section_path": "续航异常排查 › 1. 现象确认",
      "content": "…",
      "char_count": 123,
      "char_start": 0,
      "char_end": 123,
      "source_path": "knowledge/repair/续航异常排查.md"
    }
  ]
}
```

## 5. 验收

```bash
python scripts/build_kb_chunks.py
python -c "
import json
from pathlib import Path
p = Path('data/knowledge/chunks.json')
d = json.loads(p.read_text(encoding='utf-8'))
assert d['version']=='v1'
assert d['stats']['docs'] >= 15
assert d['stats']['chunks'] >= d['stats']['docs']
assert all(c['kb_chunk_id'] and c['content'].strip() for c in d['chunks'])
print('ok', d['stats'])
"
```
