# RAG · 索引库与检索器（R2）

> **喂食核心 · RAG R2**  
> 输入：`data/knowledge/chunks.json`  
> 产物：`data/knowledge/tfidf_index.json`  
> 实现：`shared/rag/tfidf_index.py` · `shared/rag/tokenize.py`  
> 构建：`scripts/build_kb_index.py`  
> 统一出口：`DataFetcher.search_kb` / `get_kb_chunk`（Tool `search_kb` 不变）  
> 版本：V1.0 · 2026-08-05

---

## 1. 目标

在切块之上建立可落盘、可重跑的检索索引，使：

1. RAG 控制环与 ReAct 工具共用同一 `search_kb`  
2. 命中返回**稳定** `kb_chunk_id` + 块正文（非临时 `#chunk{i}`）  
3. 一期 **零重依赖**（纯 Python TF-IDF，不强制 numpy/sklearn）

---

## 2. 索引方案

| 项 | 选择 |
|----|------|
| 算法 | TF-IDF + 余弦相似度 |
| 分词 | 空白切分 + CJK 二字/三字 n-gram（`shared/rag/tokenize.py`） |
| 标题加权 | `title` / `section_path` 词 × `title_boost`（默认 1.35） |
| 域过滤 | `domain=` 在打分前过滤 `kb_domain` |
| `index_id` | `tfidf_charngram_v1` |

不建：生产级 ANN、embedding API、分部门独立索引文件（域是字段过滤，不是多库）。

---

## 3. 落盘位置

| 路径 | 角色 |
|------|------|
| `data/knowledge/chunks.json` | R1 切块输入 |
| **`data/knowledge/tfidf_index.json`** | **R2 索引产物（vocab + idf + 稀疏向量 + 块正文）** |
| `docs/rag/05-索引库与检索器.md` | 本文 |
| `scripts/build_kb_index.py` | 构建入口 |
| `scripts/smoke_kb_index.py` | 冒烟 |

维护约定：`generate_synthetic_data.py` **不覆盖** `tfidf_index.json`。源 md 或 chunks 变更后执行：

```bash
python scripts/build_kb_chunks.py
python scripts/build_kb_index.py
```

## 5. 运行时接通

```text
Tool search_kb
    → DataFetcher.search_kb
        → KnowledgeSource.search_chunks
            → TfidfIndex.search  （若缺索引则关键词扫 chunks.json）
```

| API | 行为 |
|-----|------|
| `search_kb(q, domain, top_k)` | 返回 `KbChunk` 列表：真实 `kb_chunk_id` + 块 `content` + `kb_score` |
| `get_kb_chunk(id)` | 按 id 回读块（引用展开） |
| `get_kb_document(doc_id)` | 仍返回整篇 md（`#full`） |

## 8. 关于两则判断的裁定（2026-08-05）

| 判断 | 裁定 |
|------|------|
| 「R3 才是真正可演示节点，R2 还没跑通」 | **不准确**。R2 已落盘 `tfidf_index.json`，`search_kb`/`smoke_kb_index` 已跑通——**检索层可演示**。R3 是 Skill **契约**；**Agent 可演示**要到 R3+R4（控制环）。R3  alone 不能代替「跑通」。 |
| 「TF-IDF 在 Demo 阶段吃力不讨好」 | **对本仓库不成立**。蓝图明确「本地 TF-IDF / 避免重依赖」；当前三域金标问句均命中正确文档。分数绝对值偏低是 n-gram 余弦常态，已用**查询期短语/标题加权**改善观感，**不**改为 embedding 重依赖。 |

可演示分层：

```text
R2 检索 Demo  ✅（Tool / DataFetcher）
R3 Skill 契约 ✅（可加载配置；本步）
R4 控制环     → 真正「RAG Agent」端到端答问
```
