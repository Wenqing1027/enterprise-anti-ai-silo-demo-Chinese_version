智能填单 F-SVC-001 一期可试用

对话生成工单草案并写入共享产出

Control Loop

Act

Tools（工具边界）

工具类 read + write_govern。本功能实际会用到：读业务实体（客户、车辆、工单、工单列表）；整理/写共享/把关（抽工单字段、建议主题标签、标签字典、写入共用产出）。

相处模式

协作 — 业务发起多步查询/填单；写共享前需符合白名单

Skill 搭建逻辑

「智能填单」能力包搭建逻辑（fill_ticket · Act）

  1. 调用哪些业务数据/知识：客户、车辆、既有工单（主数据）；必要时标签字典
  2. 做什么样的处理：核对身份与未结工单 → 从对话原文抽工单字段并建议主题标签 → 组装工单草案
  3. 交给什么样的模型/办事方式：多步办事模型（Act）：决定查什么、何时写入；字段抽取可用规则工具辅助
  4. 调用哪些工具能力：读客户/车辆/工单；抽字段与打标；写入共用产出供续费等读取
  5. 产出什么、如何被下游使用：工单草案 + 投诉类标签进入共用层；一次运行只完成填单，不自动触达

Skill 搭建逻辑

「智能填单 · 信息整理」能力包搭建逻辑（ticket_fields · Extract）

  1. 调用哪些业务数据/知识：客服/用户原文；客户与车辆 ID（若提供）
  2. 做什么样的处理：按工单草案 schema 抽取类型、摘要、标签、情感、是否投诉等字段并校验齐全
  3. 交给什么样的模型/办事方式：信息整理模型（Extract）：偏结构化抽取与校验，不做多步查库脑回路
  4. 调用哪些工具能力：以 schema 校验为主；需要沉淀时再写入共用产出
  5. 产出什么、如何被下游使用：结构化工单草案，可与填单功能并行，供坐席确认或下游读取
